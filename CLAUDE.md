# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

This is a single-file HTML application (`planner.html`) for planning rides at Knoebels amusement park. It lets users add people, rate each ride by tier (Must do / Want to do / Maybe / Nope), and see per-person and group ticket cost estimates.

There is no build system, package manager, or test suite. Development is open-the-file-in-a-browser.

## Architecture

Everything lives in one file with three sections:

1. **`<style>`** — Inline CSS using CSS custom properties (`--color-*`, `--border-radius-*`, etc.) supplied by the host environment (the file is designed to be embedded, not used standalone). Tier active states have hardcoded color values (`active-must`, `active-want`, `active-maybe`, `active-nope`).

2. **HTML** — A minimal shell with two views (`#view-rides`, `#view-summary`) toggled by `showView()`, a person tab bar (`#person-tabs`), and a ride list (`#rides-list`).

3. **`<script>`** — Vanilla JS with no dependencies. Key data structures:
   - `RIDES` — static array of `{name, price}` objects (all ~58 Knoebels rides with current ticket prices)
   - `persons` — array of `{name, id}` objects; IDs generated by `uid()`
   - `ratings` — object keyed by person ID, then by ride index → tier string (`"must"` | `"want"` | `"maybe"` | `"nope"`)
   - `activePerson`, `activeFilter`, `currentView` — UI state

   State mutations always end with a `render*()` call. There is no reactivity framework — rendering is full re-renders via `innerHTML`.

## Key behaviors

- **Toggling a tier**: clicking the active tier button removes the rating (acts as a toggle off), handled in `setTier()`.
- **Filtering rides**: `setFilter()` accepts `"all"`, `"must"`, `"want"`, `"maybe"`, `"nope"`, or `"unset"` and updates `activeFilter`.
- **Cost calculation**: `calcCost(pid, tiers)` sums prices for all rides where that person's rating is in the given tiers array.
- **No persistence**: all state is in-memory; refreshing the page resets everything.
- **Avatar colors**: `avatarColor(id)` cycles through a fixed palette of background/text color pairs, indexed by position in the `persons` array.
- **Ticket tip**: the summary view includes a hardcoded note that Knoebels ticket books come in $5/$20/$50 denominations and never expire.
